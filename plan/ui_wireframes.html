Окно 3 — Шаг паспорта (единая форма шага)

5 кадров пошагово: фас-портрет → фас-рост → профиль → спина → 3/4. Своё предупреждение/критерий на каждом. 3 ИИ-кнопки. См. §5 «Паспортные кадры».

ШАГ 1 / 5 · Фас-портрет
Это базовый кадр идентичности. Критерий: чёткий фас, лицо прямо в камеру, head&shoulders, нейтраль, серый фон, без рамок/надписей.
[FACE] — только анатомия
oval face, high cheekbones, straight nose, blue eyes, black shoulder-length hair, scar on left cheek
писать: форма лица, нос, губы, глаза, волосы, кожа, шрамы/тату. не писать: выражение лица/эмоцию (→ EXPRESSION), позу/фон (→ COMPOSITION), одежду (→ OUTFIT).
[OUTFIT] — базовый наряд (ВВОД здесь, плечи в кадре; докрутка на фас-рост)
dark fur-trimmed leather tunic
писать: одежду, материал, крой, цвет наряда. не писать: телосложение (→ BODY), лицо (→ FACE), позу/фон (→ COMPOSITION), эмоцию (→ EXPRESSION).
превью кадра
Проверить с ИИ Правка с ИИ Сгенерировать
← Назад Утвердить Вперёд →

Поведение

  • Шаг 1 крутит [FACE] → утвердил → FACE заморожен, кадр = реф лица.
  • Шаг 2 (фас-рост) крутит [BODY], лицо держит реф → утвердил → BODY заморожен, и базовый наряд (введённый на экране данных) тоже морозится здесь.
  • Шаги 3–5 (профиль/спина/3/4): поле OUTFIT read-only серым, EXPRESSION принудительно neutral.
  • Проверить с ИИ — 1 слой/кадр; Правка с ИИ — весь персонаж, ставит need_regen.
  • Вход в шаг: если раньше есть шаг с need_regen — прыжок туда. «Вперёд» активна только если есть данные след. шага.
  • Гейт: все 5 утверждены → следующая фаза.

Дальше: Окно 4 (эмоции, если вкл) → Окно 5 (наряды, если вкл) → Окно 6 (датасет).

Поведение

  • Первая генерация делает сразу: фас-рост + сзади-рост (+ профиль-рост если «Сложный»).
  • Галочка «утв.» — только чтобы перегенерация не трогала утверждённые сцены (не для разблокировки кнопки).
  • Согласовать наряд заблокирована, пока нет генераций всех обязательных сцен (фас+сзади, +профиль для сложного).
  • Деталь опциональна; генерится без идентичности. «Удалить» с генерацией → «Вы уверены?». Можно несколько деталей.

  • Выключил «Сложный» после профиля → реф профиля прячем, не удаляем.
  • При согласовании: последние генерации → утверждённые рефы, все промты + флаги в state.

Окно 7 — Фаза датасета (массив композиций)

Финальная фаза: проход по сохранённому массиву композиций, авто-генерация + отбор. См. §4 (флоу) и §5.

Конан · датасет · композиция 4/12
превью кадра композиции
[COMPOSITION] — поза + ракурс + кадр + фон
walking pose, three-quarter angle, full body, tavern interior background
писать: позу, ракурс, план кадра, фон/локацию. не писать: лицо/телосложение (держат рефы), одежду (→ активный OUTFIT), эмоцию (→ EXPRESSION).
активный OUTFIT: парадный доспех · EXPRESSION: grim, brooding (базовая)
проверка llm Перегенерить
Утвердить → approved/

Поведение

  • Авто-генерация по текущей композиции массива + активный OUTFIT + базовая эмоция.
  • проверка llm сверяет картинку против промта (формат {обоснование}[промт]).
  • Утвердил → approved/ (имя по композиции). Кнопки «Отклонить» нет.
  • При перегенерации предыдущая генерация НЕ теряется — уходит в rejected/ (+ № попытки). Отклонённые НИКОГДА не удаляются (вдруг пригодятся для датасета).
  • Рандомный фон: хардкод-массив + random.choice() + поле override.
  • Массив закончился → завершение: current_step → null, финальный архив.

Готово: архив с семплами (approved/ + rejected/).
